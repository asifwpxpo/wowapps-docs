# Analytics

The Analytics page helps you track the performance and revenue generated from WowOptions on your Shopify store. It provides a clear overview of how customers interact with your product options and how much revenue each option generates.

## Date Range

Use the date range selector to filter your analytics data. Available presets are:

- Last 7 days
- Last 30 days
- Last 90 days
- All time

All metrics and data tables will update based on the selected date range.

## Key Metrics

At the top of the page, you'll see a summary of important performance indicators.

- **Total Revenue**: The total revenue generated from orders that include WowOptions.
- **Orders with Options**: The number of orders that included at least one option.
- **Average Order Value**: The average value of orders that include options.
- **Options Revenue**: The total revenue generated specifically from selected options (extra charges).

These metrics give you a quick understanding of how your product options are performing.

## Options Performance Table

This section shows how individual options are performing. Each row includes:

- **ID** — The unique identifier of the option
- **Name** — The name of the option
- **Amount** — The revenue generated from that option
- **Number of Orders** — How many times the option was selected in orders

Use this table to identify your most popular and highest-performing options.

## Orders with Options

This table displays detailed information about orders that include WowOptions.

Each row includes:

- **Order** — The order number (clickable for reference)
- **Date** — The date the order was placed
- **Total** — The total order value
- **Options Revenue** — The revenue generated from selected options in that order
- **Options** — The options selected in the order

This helps you understand how options contribute to individual orders.
