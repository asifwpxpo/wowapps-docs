# WowOptions Fields Overview

WowOptions includes 23 customizable option fields that allow you to add flexible product options and personalization features to your Shopify products. These fields help you collect customer input, display additional information, and create interactive product customization experiences.

Below are the available field types grouped by category.

## Layout Fields

These fields help structure and organize your product option layout.

- Divider
- Spacer
- Group

## Text Fields

These fields allow customers to enter text or display additional content on the product page.

- Text Field
- Text Area
- Content

## Interactive Fields

These fields add interactive elements that enhance the product customization experience.

- Button
- Modal
- Range Slider

## Form Input Fields

These fields collect specific types of customer information.

- Phone
- Number
- Email
- Link
- Date & Time

## Selection Fields

These fields allow customers to choose one or multiple options.

- Dropdown
- Checkbox
- Radio
- Switch

## Media & Color Fields

These fields allow customers to upload files, select colors, or choose visual product options.

- Upload
- Image Swatch
- Color Picker
- Color Swatch
- Product Swatch

## Advanced Features

WowOptions also supports Conditional Logic and Global Style, allowing you to create more advanced product configurations.

With these features, you can:

- Show or hide fields based on customer selections
- Control how option fields appear on the product page
- Apply consistent styling across all option fields
