
# App Introduction

WowOption, the best custom product option app helps Shopify merchants to sell personalized products without being limited by Shopify native variant restrictions. Add unlimited custom product options, custom price options and flexible add-on options directly to your product page. Apply particular options set to appropriate products and create smarter product page variations with conditional logic and pricing rules that increase average order value. No complex setup required, No code required.

### What You Can Do:

- Add unlimited custom product options beyond Shopify's built-in variant limits.
- Create flexible custom price options like fixed fees, percentage pricing or per character charges.
- Build smart product page variations using conditional logic that shows or hides options automatically.
- Offer revenue-driving add-on options to increase your average order value.
- Collect text inputs, file uploads, dates, swatches, dropdowns and more from customers.
- Apply option sets to multiple products in just a few clicks.
- Manage all customization settings from one simple, easy-to-use dashboard.
