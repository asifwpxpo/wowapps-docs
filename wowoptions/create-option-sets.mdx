# Create Option Sets

To start adding custom options:

## Go to Option List

Click Create Option Set → Create from Scratch

## Add Option Fields

1. Click Add your first option
2. Select the field type you need (e.g., Text Field, Dropdown, Checkbox, etc.)
3. Configure the field based on your product requirements

## Conditions Tab (Visibility Logic)

The Conditions tab allows you to control when an option or group is displayed. Use conditional logic to show or hide fields based on specific criteria, such as:

- A specific variant is selected
- Another option is checked
- A quantity condition is met

### Common use cases:

- Show Gift Options only when the gift checkbox is selected
- Show Custom Engraving only for specific product variants

### Notes:

- You can combine multiple rules using Any (OR) or All (AND)
- It is recommended to test conditions on the product page to ensure expected behavior

## Save and Assign

After configuring your options:

1. Enter an Option Name for identification
2. Assign the option set using Add to Products
3. Click Save from the top-right corner

This ensures the option set is saved and applied to the selected products.
