# Conditional Logic

Conditional Logic in WowOptions helps Shopify merchants show or hide product option fields based on what customers select. Instead of showing every option at once, merchants can create a cleaner and smarter product page where customers only see the fields that are relevant to their choices.

For example, if a customer selects Add Engraving, you can show a text field for the engraving message. If they do not select engraving, that field stays hidden.

## When and Why You Should Use Conditional Logic

Use Conditional Logic when your product has options that depend on previous customer selections. Some products do not need every field to appear for every customer. Showing too many fields at once can make the product page look long, confusing, or difficult to complete. Conditional Logic solves this by creating a more guided customization flow.

For example, a custom hoodie store can first ask:

Do you want personalization?
If the customer selects Yes, then the store can show:

* Name text field
* Font style
* Text color
* Upload logo field

If the customer selects No, those fields stay hidden.

Conditional Logic helps merchants:

* Keep product pages clean and focused
* Reduce unnecessary fields
* Make complex products easier to customize
* Show relevant options at the right time
* Reduce customer confusion before checkout
* Collect cleaner order details
* Create a smoother product customization experience

This feature is especially useful for personalized products, custom gifts, print-on-demand items, made-to-order products, service add-ons, upload-based products, and products with multiple customization paths.

## Supported Option Types

Conditional Logic can be applied to option fields that need to appear or hide based on customer selections. WowOptions includes multiple option types such as Button, Checkbox, Color Swatch, Dropdown, Image Swatch, Product Swatch, Radio, Switch, Text Field, Text Area, Upload, and more.

You can commonly use Conditional Logic with:

* Button
* Checkbox
* Color Swatch
* Dropdown
* Image Swatch
* Product Swatch
* Radio
* Switch
* Text Field
* Text Area
* Upload
* Number
* Date & Time
* Email
* Phone

Before publishing, preview the option set to make sure the field appears or hides exactly as expected.
