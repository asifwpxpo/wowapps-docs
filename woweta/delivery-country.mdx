# Delivery Country

You’ll be able to select estimated delivery dates for specific countries. You can also set the estimated shipping times for these countries. To add a new country, all you have to do is:

- Select a new zone
- Set the range type
- Set the delivery time

![WowETA Delivery Country Add](/docs/woweta-delivery-country-add.png)

You can change the delivery time for each country and worldwide.

_Do note that you need to manage the shipping zone from the ‘shipping and delivery’ section of your Shopify store settings. There’s a direct link in the delivery country setup that’ll directly take you to ‘shipping and delivery’._

![WowETA Delivery Country](/docs/woweta-delivery-country.png)

_Please note that the country selection is rule-specific. So, if you have a specific ETA rule where you need to show delivery dates for specific countries for specific products, make sure to enable it from the ETA rule._
